1. Can the value of the string (sentence) be changed with the modified function prototype? If so, how?

    - You can change the original string directly by passing the string parameter by reference (std::string &sentence) or by pointer (std::string *sentence).

2. Compared to using reference variables, what other modifications are required when making the
function call and inside the function?

    - When calling the function, pass the address of the variable &. Inside the function, you need to use the dereference operator * to access and modify the value of the parameter.

3. What is the difference between an ampersand (&) and an asterisk (*) added in front of the parameter?

    - The ampersand & indicates that a parameter is passed by reference. This allows the function to operate directly on the original variable, enabling modifications without copying the value.The asterisk * indicates that a parameter is a pointer. A pointer stores the memory address of a variable. When using a pointer parameter, the function must dereference * the pointer to access or modify the value at that memory address.
